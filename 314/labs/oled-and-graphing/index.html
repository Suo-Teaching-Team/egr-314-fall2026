    Lab: ESP32 and Graphing

    Individual Assignment

    Introduction

    In this lab, you will learn how to utilize the I2C module built into the ESP32 to control an OLED display with a simple state machine, which you will be able to use on your project.

    Objectives

    • To learn and explore the functionality of the ESP32's built in I2C module
    • To program the ESP32 using VSCode
    • To have a working display that can be used on your semester project

    An individual live demonstration is required. You may work in pairs (one partner), but must individually demonstrate your working breadboard.

    Parts Needed

    Item Quantity
    ESP32 Development Board 1
    Breadboard 1
    Jumper wires ~10
    USB Micro Cable 1
    OLED Screen 1

    Instructions

    1. Clone the ESP32_Oled project to your local pc: https://github.com/embedded-systems-design/code_esp32_oled. Take a look inside.

      1. Remember that boot.py and main.py are the two files that get run automatically
      2. import loads other files and runs what's inside.
      3. what's inside my_oled.py?
      4. what pins are used for SCL and SDA?

    2. Wire up your OLED to your ESP32, using the pinouts you just discovered.

      Note: OLED image is not representative of actual module or pin order

    3. Go back to main.py. At the bottom, create a while loop that continues forever:

      while True:
    pass

      pass simply is a line that means "do nothing". You always need something in a while loop, for loop or if statement.

    4. at the top of main.py, import the time library:

      import time

    5. add a pause inside your while loop:

      while True:
    pass
    time.sleep(1)

      Now that you have something in the while loop, you can comment out the pass statement

    6. Create an "state" variable that holds states. Initialize it right before the while loop:

      state = 0

    7. Increment the state variable each time you go through the while loop.

      state = state+1

    8. Inside the while loop, after incrementing state, if state is equal to 4 or greater, reset it to zero.

    9. How do you know if it's working? print the current value of state each time it cycles through while with print(state). Put it right below while True:

    10. Inside the while loop, if the state is equal to zero, have your program perform the following action:

      my_oled.print_text("test",0,0)

    11. Inside the while loop, if the state is equal to one, have your program perform the following action:

      my_oled.print_text("something else",0,0)

    12. look at the my_oled.py file. See what the print_text() function does.

      • identify the fill(0) function. What does the code say is happening?
      • identify the show() command. What does the code say is happening?

    13. Modify my_oled.print_text("something else",0,0) so the text prints on the bottom row of the OLED.

    14. Inside the while loop, if the state is equal to 2, have your program perform the following action:

      1. clear the screen
      2. draw a line
      3. show the screen

      to draw a line, try my_oled.oled.line(0,0,10,10,1)

    15. Now, modify your code so that you draw a line from the bottom left of the screen to the top-right of the screen

    16. Inside the while loop, if the state is equal to 3, have your program perform the following action:

      1. clear the screen
      2. draw a filled rectangle
      3. show the screen

      to draw a filled rectangle, consider using the my_oled.graphics.fill_rect(0,0,10,10,1)

    17. Now, modify your code so that you draw a filled rectangle that covers the bottom-right quadrant of the screen.

    18. Finally, look in the lib/gfx.py module. What other functions can you implement?
    19. (optional) look inside my_oled to see how print_text() was implemented. How could you simplify your while loop by bringing your plotting functions inside the my_oled.py module?

    Demonstration of Proficiency

    Please be prepared to demonstrate

    1. Cycling through states 0,1,2,3 in the terminal
    2. Printing text on the top and bottom of the screen
    3. Drawing a line from the bottom left to the top right corner of the screen
    4. Drawing a filled rectangle in the bottom-right quadrant of the screen.
