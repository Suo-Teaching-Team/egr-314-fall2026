## Instructions

1. Read through the instructions in the "[How to fork the report repository](https://embedded-systems-design.github.io/fork-report-website/)" tutorial.

1. Install Git and all necessary support programs:

    1. Windows:

        1. Git for Windows
        1. Git Extensions(highly suggested) or Github for windows
        1. KDiff3

1. Set up Git and Git extensions.  When you first open Git Extensions you will need to

    1. Define your full name
    2. Define your email address
    3. Link Kdiff to the comparison and merging tool

1. Log in to your existing (or create a new) personal profile on github.
1. Create a new **public** repository and personal webpage using the tutorial.

1. Once set up, you must then individually demonstrate "pushing" one "commit" to the team repository.  Using Git Extensions,

    1. Clone the repository to a local folder on your website
    1. Pull the most recent version
    1. Add or edit at least one file on your pc.
    1. Create a commit

        1. Stage all edited files
        1. Add a message about your edits
        1. Commit
        1. Push

    > Note: The first time you do this you may need to authenticate with github.

## Submission

Submit the following information in Canvas

1. The url to your personal profile, eg ```https://github.com/<your-user-name>```
2. The url to your personal website hosted on github, eg ```https://<your-user-name>.github.io```

The website should be working and filled with your information, and the repository show at least one successful commit.

## Demonstration

We will use your user name and public team repository to verify you successfully pushed a commit to your team's public report repository.
